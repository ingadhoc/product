=======================
Product Pack Product UX
=======================

Makes the "Pricelist Price" field of "Product UX" show, on a product pack, the
price the order would apply: the pack plus its components, with the pricelist
and the currency of the order the catalog was opened from.

Installation
============

To install this module, you need to:

#. Just install this module.

Configuration
=============

To configure this module, you need to:

#. No configuration needed.

Usage
=====

To use this module, you need to:

#. Set a product as a pack, displayed as detailed and with component prices
   detailed per component.
#. Open the product catalog from a sale order and add the "Pricelist Price"
   column.
